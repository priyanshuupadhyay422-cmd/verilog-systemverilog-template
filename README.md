# Verilog and SystemVerilog Template Library

A collection of reusable Verilog and SystemVerilog code templates designed to help students, FPGA developers, RTL designers, and VLSI enthusiasts learn digital design, accelerate development, and practice hardware description languages.

## Project Links

- **GitHub Repository:** [Verilog and SystemVerilog Template Library](https://github.com/priyanshuupadhyay422-cmd/verilog-systemverilog-template)
- **Live Website:** [Explore the Template Library](https://verilog-systemverilog-template-libr.vercel.app/)
- **Local Development Website:** [Open Locally](http://127.0.0.1:5500/.vscode/index.html)

> The local development link works only on your computer while your local server is running. Use the live website to access the project online.

## About the Project

The Verilog and SystemVerilog Template Library is a learning and development resource for digital electronics and hardware description languages. It provides an organized collection of code templates and explanations to help users understand RTL design concepts and implement digital circuits more efficiently.

Whether you are preparing for VLSI interviews, learning RTL design, working on FPGA projects, or exploring ASIC design flows, this library can serve as a practical reference.

## Features

- Collection of reusable Verilog and SystemVerilog templates.
- Organized code examples for easier learning and reference.
- Beginner-friendly resources for digital logic and RTL design.
- Useful for FPGA development and ASIC design practice.
- Supports learning through practical hardware description language examples.
- Accessible through a web-based interface.
- Suitable for students, hobbyists, and aspiring VLSI engineers.

## Topics Covered

The library can be used as a reference for digital design topics such as:

- Combinational Logic
- Sequential Logic
- Multiplexers and Demultiplexers
- Encoders and Decoders
- Adders and Subtractors
- Latches and Flip-Flops
- Counters and Registers
- Finite State Machines (FSMs)
- Shift Registers
- Testbenches and Simulation
- Verilog HDL
- SystemVerilog

The exact topics available depend on the templates included in the repository.

## Getting Started

### Option 1: Use the Website

Visit the online library:

[Open the Verilog and SystemVerilog Template Library](https://verilog-systemverilog-template-libr.vercel.app/)

Browse the available templates and use them as references for your projects.

### Option 2: Clone the Repository

Make sure Git is installed on your computer.

Open a terminal and run:

```bash
git clone https://github.com/priyanshuupadhyay422-cmd/verilog-systemverilog-template.git
```

Navigate to the project directory:

```bash
cd verilog-systemverilog-template
```

Open the project in Visual Studio Code:

```bash
code .
```

Open the website's HTML file using your preferred local development server or browser, depending on the project structure.

## Recommended Tools

The following tools can help you work with the templates:

- **Visual Studio Code** — code editing.
- **Icarus Verilog** — Verilog compilation and simulation.
- **GTKWave** — waveform visualization.
- **AMD Vivado** — FPGA synthesis, implementation, and simulation.
- **QuestaSim** — HDL simulation and verification, where available.

These tools are optional and depend on the specific template and workflow you want to use.
